# 结果与适用范围

## 三个模型身份

1. **基线**：2500 轮训练中的 epoch 2478 最优 checkpoint。原 64 条 test 的 E/H/P 平均相对 L2 为 0.59675%／0.87204%／0.59645%。
2. **A 组**：基线后用原 MSE 做 4800 次受控更新，step 4224 被共同验证指标选出。它是四组验收和示例使用的冻结模型。
3. **B 组**：相同起点、更新预算、样本顺序和学习率，使用混合损失；step 4152 为其最优验证模型。主指标略差于 A，不宣称改善。

基线 test 与 A/B validation、四组新验收不是同一个人群，不能拼接成一项总体精度。A/B 最优 step 可不同，但完成的训练预算相同。历史多次续跑也不是多随机种子的独立重复。

## 四组验收

完整统计见 [验收报告](../evidence/acceptance/REPORT_验收结论.md)。G1/G2 的数值工作门槛初步满足：每场平均相对误差≤2%，且至少 15/16 条三场同时≤5%。报告中人工复核仍未关闭。

G3/G4 使用宽而平滑的紧支撑脉冲，误差显著增大且均为 0/16 达到三场≤5%。这说明当前训练分布不足以支撑这些新函数输入上的准确性。不能仅因 FNO 接口接受一组新网格值，就声称已经学会任意初值算子。

H 的常量模态、其他均值、高频尖峰、更细网格、其他终点、未知历史均未获得本项目验收。已公开验收案例可作回归或开发资料，后续改进若要报告独立泛化结果，需另设新家系和材料。

## 标签和参考

训练数据保留 11 帧，但 FNO 只用 T=1。三模态标签有独立模态公式的数值核验；新函数参考依靠预定样本的单独时空细化。后者是经验质量控制，不能写成严格真误差上界。

## 速度

历史测试为 CPU 单线程、FNO float32 与 DG float64。常驻 FNO 包括编码、张量转换、前向、反归一化；DG wrapper 还包括连续初值投影、进程启动、文件 I/O 和检查。CQ 磁盘缓存可复用，LU 未跨查询常驻复用。

约 500 的 wrapper 时间比只描述这些实现与指定配置。尚未完成同精度成本前沿校准、谱响应基线比较或离线成本回收验证。精度未通过的 G3/G4 不具有同精度加速结论。
